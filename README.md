# MO TO-DO List 
*📖 Description*

Mo To-Do List is a lightweight, console-based productivity application built in C++. It enables users to efficiently manage daily tasks by adding, updating, deleting, sorting, and searching through tasks directly from the terminal.

The application uses file-based storage to ensure tasks are automatically saved and persist between sessions.

*🧠 Project Overview*

This project helps users:
•Track personal or academic tasks
•Prioritize tasks based on importance
•Mark tasks as completed and monitor progress
•Automatically save tasks using file storage
•View task summaries and completion percentages

*⚙️ Features*

•Add, edit, and delete tasks
•Search and sort tasks
•Mark tasks as complete/incomplete
•Persistent storage using a file (tasks.txt)
•Progress tracking with completion statistics

*🧱 File Structure*

main.cpp     → Main source code  
tasks.txt    → Stores task data  
README.md    → Project documentation

*💻 How to Run*

1. Clone the repository
git clone <your-repo-link>
cd MO-TO-DO-List

2. Compile the program
g++ main.cpp -o ToDoList

3. Run the program
./ToDoList

*📌 Notes*

The program automatically creates and updates tasks.txt
All tasks are saved between sessions
